# Independently checked sequential sensor replay

The original 27-file owner freeze is retained byte for byte. Root verified every hash, independently passed all five tests with the repository uv environment, and visually checked the coverage figure. Reproduce the tests from this directory using `uv run python -B -m unittest discover -s . -p 'test_*.py'` from an appropriately configured workspace.

This is synthetic flat-scene acquisition along recorded C-study motion. It measures time-dependent optical coverage with exact included robot meshes; it does not qualify camera hardware, mounting fit, terrain traversal or safe support. The production-derived hypothetical mounts remain a different lineage from the C simulation assembly. Original reproduction commands remain preserved in README.md.
